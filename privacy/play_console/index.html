요약

개발자 콘솔 - PC화면 바로가기는 공식 웹 콘솔 주소를 외부 브라우저로 전달하는 도구입니다. 계정·비밀번호·브라우저 쿠키를 앱에 저장하지 않으며, 웹 페이지의 로그인 상태나 작업 결과를 읽지 않습니다.

기기에 저장되는 정보

  • 사용자가 저장한 즐겨찾기, 화면 설정, 선택한 열기 방식(외부 브라우저)을 기기에 저장합니다.
  • 최근 열기 기록을 켠 경우 열었던 허용 경로와 시각을 기기에 저장합니다. 설정에서 기록을 끄거나 전체 삭제할 수 있습니다.
  • 사용자가 선택한 백업 파일에는 즐겨찾기와 화면 설정만 포함됩니다. 최근 기록·계정·쿠키·웹 입력 내용은 포함하지 않습니다.
  • 백업 파일을 다른 앱으로 보내는 경우 파일 전달은 사용자가 선택한 앱이 처리합니다.

전송되는 정보

Google 서비스 SDK

광고를 제공하기 위해 Google Mobile Ads SDK를 사용합니다. 광고 SDK는 광고 ID, 대략적인 위치, 광고 상호작용, 앱 정보·성능 및 진단 정보를 수집하거나 공유할 수 있습니다. Google Analytics for Firebase는 화면 조회와 앱 상호작용을 측정할 수 있습니다. Google의 처리 방식은 해당 Google 서비스의 최신 정책과 공개 안내를 따릅니다.

익명 사용 통계

출시 빌드에서는 Owlmakers의 공용 pulse 서버로 다음과 같은 사용 통계를 전송할 수 있습니다: 앱 식별자, 앱 버전, 임시 세션 식별자, 언어, 이벤트 종류와 고정된 화면·기능 이름, 시각. 서버는 요청의 네트워크 헤더에서 국가·시·도·도시 이름을 추정할 수 있지만 원본 IP 주소와 좌표를 저장하지 않습니다. URL 전체, 계정, 비밀번호, 쿠키, 파일 이름과 웹 입력 내용은 이 통계에 넣지 않습니다.

광고·통계 전송은 네트워크 상태나 SDK 상태에 따라 실패할 수 있으며, 실패해도 앱의 기본 기능은 계속 동작합니다.

외부 브라우저와 공식 서비스

앱은 사용자가 요청한 허용 주소를 외부 브라우저에 전달합니다. Google 계정 로그인, 쿠키, 웹 페이지 내용과 작업 완료 상태는 브라우저와 해당 웹 서비스가 처리합니다. 이 앱은 Google LLC의 공식 앱이 아니며 Google과 제휴하지 않습니다.

보관과 삭제

기기 데이터는 Android 또는 iOS의 앱 데이터 삭제·앱 제거로 삭제할 수 있습니다. 사용자가 만든 백업 파일은 파일 관리자에서 직접 삭제해야 합니다. Owlmakers의 pulse 서버에는 임시 세션·이벤트 통계가 최대 1년 보관될 수 있으며, 계정 식별 정보는 저장하지 않습니다. 문의: support@owlmakers.com

아동

이 앱은 만 14세 미만 아동을 대상으로 설계하지 않았습니다.

변경

서비스 또는 SDK의 처리 방식이 바뀌면 이 문서를 갱신하고 시행일을 변경합니다.
