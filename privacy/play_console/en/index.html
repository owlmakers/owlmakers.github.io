Privacy Policy — Play Console - Desktop View

Effective date: October 13, 2026 · Contact: support@owlmakers.com · 한국어: open

Summary

Play Console - Desktop View hands an official web console URL to your external browser. The app does not store accounts, passwords, or browser cookies, and it does not read web sign-in state or task completion.

Information stored on your device

  • Bookmarks, display settings, and the external-browser opening mode are stored on the device.
  • If recent opens are enabled, the app stores allowed paths and timestamps on the device. You can turn history off or clear it in Settings.
  • A backup file selected by you contains bookmarks and display settings only. It excludes recent opens, accounts, cookies, and web form input.
  • If you send a backup to another app, the app you choose handles that file transfer.

Information sent from the app

Google service SDKs

Google Mobile Ads SDK is used to provide advertising. The advertising SDK may collect or share an advertising ID, approximate location, ad interactions, app information and performance, and diagnostics. Google Analytics for Firebase may measure screen views and app interactions. Google’s current policies and disclosures govern those services.

Anonymous usage statistics

Release builds may send the following usage statistics to Owlmakers’ shared pulse server: app identifier, app version, a temporary session identifier, language, event types and fixed screen or feature names, and timestamps. The server may infer country, province, city, or district names from network headers, but it does not store the source IP address or coordinates. Full URLs, accounts, passwords, cookies, file names, and web form input are not included.

These SDK and statistics requests can fail because of network or service conditions. The app’s core features continue to work when they fail.

External browser and official services

The app hands an allowed URL to your external browser when you request it. Google account sign-in, cookies, web content, and task completion are handled by the browser and the relevant web service. This app is not an official Google LLC app and is not affiliated with Google.

Retention and deletion

Device data can be deleted by clearing the app’s data or uninstalling it in Android or iOS settings. Backup files you create must be deleted from your file manager. Temporary session and event statistics may remain on Owlmakers’ pulse server for up to one year; account identifiers are not stored. Contact: support@owlmakers.com

Children

This app is not designed for children under 14.

Changes

If the service or SDK data handling changes, this policy will be updated with a new effective date.
