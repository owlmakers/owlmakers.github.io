개인정보처리방침 — 사진 자르기 - 일괄 비율 크롭

최종 수정일: 2026년 10월 13일 · English

Owlmakers(이하 "개발자")는 「사진 자르기 - 일괄 비율 크롭」(영문 표기 Photo Crop - Batch & Ratio, 이하 "본 앱")를 이용하는 사용자의 개인정보를 중요하게 생각하며, 아래와 같이 처리 방침을 안내합니다.

핵심 요약
· 사용자가 고른 사진은 기기 안에서만 처리됩니다. 개발자의 서버나 제3자에게 사진·파일 이름·촬영 위치를 보내지 않습니다.
· 본 앱에는 계정·로그인·회원가입이 없고, 개발자가 운영하는 서버도 없습니다.
· 본 앱은 저장소 전체 접근·카메라·위치·마이크·연락처 권한을 요청하지 않습니다. 사진은 안드로이드 사진 선택 화면에서 사용자가 직접 고른 것만 읽습니다.
· 광고(Google AdMob)와 익명 이용 통계(Google Analytics for Firebase)는 사용합니다. 사진 내용·파일 이름은 여기에 포함되지 않습니다.

1. 사진 — 이 기기를 떠나지 않습니다

  • 사용자가 사진 선택 화면에서 고른 사진만 읽으며, 자르기와 저장은 모두 사용자 기기 안에서 이루어집니다.
  • 원본 사진은 덮어쓰지 않습니다. 자른 결과는 기기의 사진 보관함(Pictures/PhotoCrop 폴더)에 새 파일로 저장됩니다.
  • 저장하는 새 사진에는 촬영 위치(GPS) 등 원본의 EXIF 메타데이터를 넣지 않습니다. 사진의 방향 정보는 결과 이미지에 반영됩니다.
  • 사진·파일 이름·사진 주소(URI)·위치를 광고 요청이나 이용 통계에 넣지 않습니다.

2. 기기에 저장되는 정보

다음 정보는 사용자 기기 안에만 저장되며 개발자에게 전송되지 않습니다.

항목내용
설정마지막으로 쓴 비율, 출력 형식(JPEG/PNG)과 화질, 테마(시스템/라이트/다크), 표시 언어, 첫 안내(온보딩) 확인 여부
진행 중인 작업고른 사진의 주소(URI)·파일 이름·크기, 사진별로 정한 자르기 영역 좌표, 처리 상태(대기·성공·실패·취소). 앱이 중단돼도 이어서 할 수 있도록 저장합니다.
결과 목록최근 저장한 결과(최대 100개)의 파일 이름과 저장된 사진 주소
백업 파일위 설정·작업·결과 목록을 담은 photo_crop_backup.json 파일. 정보가 바뀔 때마다 기기의 다운로드 폴더에 저장되고, 설정 화면의 「지금 파일로 백업」을 누르면 날짜가 붙은 사본을 따로 만듭니다. 이 파일에는 사진 자체가 들어 있지 않으며, 기기 안에만 있고 개발자에게 전송되지 않습니다. 사용자가 파일 관리 앱에서 직접 삭제할 수 있습니다.

3. 광고 — Google AdMob

본 앱은 무료 제공을 위해 Google AdMob 광고를 표시합니다.

  • 광고는 앱 화면 위쪽의 배너와 앱 종료 확인 창에 표시될 수 있습니다. 자르기·저장을 하는 중간에 전체 화면 광고를 띄우지 않습니다.
  • AdMob 은 광고 제공을 위해 광고 ID(AAID), IP 주소, 앱 사용 상호작용, 진단 정보를 수집할 수 있습니다. 이는 Google 의 처리 방침에 따르며, 개발자는 해당 정보를 별도로 수집·보관하지 않습니다. 사진과 파일 이름은 광고에 전달되지 않습니다.
  • Google 의 광고 데이터 처리: https://policies.google.com/technologies/ads
  • 광고 개인화 설정: 기기 설정 → Google → 광고 에서 변경하거나 광고 ID 를 초기화·삭제할 수 있습니다.
  • 유럽 경제 지역(EEA)·영국 사용자에게는 첫 실행 시 광고 동의(UMP) 창을 제공하며, 동의 절차가 끝나기 전에는 광고 SDK 를 시작하지 않습니다. 설정 화면의 '광고 개인정보 설정'에서 동의를 다시 바꿀 수 있습니다(해당 지역에서만 표시).

4. 이용 통계 (Google Analytics for Firebase)

본 앱은 서비스 개선과 안정성 확보를 위해 Google Analytics for Firebase 로 익명 이용 통계를 수집합니다.

  • 수집 항목 — 어느 화면(홈·자르기·결과·설정)을 열었는지, 사진을 몇 장 골랐는지(장수), 어떤 비율을 골랐는지(예: 정사각형), 저장 결과가 성공·실패·취소 몇 건이었는지와 출력 형식, 저장한 결과를 열기·공유 중 무엇으로 했는지. 그리고 설치본마다 무작위로 부여되는 앱 인스턴스 ID와 Google Analytics 가 자동으로 수집하는 정보(세션, IP 주소로 추정한 대략적인 지역, 기기·앱 버전, 광고 ID 등).
  • 수집하지 않는 것 — 사진, 파일 이름, 사진 주소, 촬영 위치, 이름·이메일·전화번호 등 개인 식별 정보.
  • 처리 주체 — 수집·처리는 Google 이 수행하며, 개발자는 개인이 식별되지 않는 집계된 통계만 열람합니다. Google 의 처리 방침: https://policies.google.com/privacy

5. 개발자 서버

본 앱은 개발자가 운영하는 서버로 어떤 정보도 전송하지 않습니다. 계정이 없으므로 개발자가 보관하는 개인 정보도 없습니다.

6. 앱이 요청하는 권한

본 앱은 저장소 전체 읽기·쓰기, 카메라, 위치, 마이크, 연락처, 계정 권한을 요청하지 않습니다. 사진은 시스템 사진 선택 화면(Android 13 이상) 또는 파일 선택 화면(Android 12 이하)에서 사용자가 고른 것만 읽습니다.

인터넷 연결(광고·이용 통계), 네트워크 상태 확인, 광고 ID 접근은 광고와 통계 SDK 의 동작에 필요한 권한이며 사용자의 사진이나 파일을 읽는 권한이 아닙니다.

7. 앱 업데이트

새 버전 안내는 Google Play 의 앱 내 업데이트 기능을 사용합니다. 이 과정에서 개발자가 사용자의 정보를 받지 않습니다.

8. 만 14세 미만 아동

본 앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 고의로 수집하지 않습니다.

9. 사용자 권리와 삭제 방법

개발자가 보관하는 개인 식별 정보가 없습니다. 기기 안의 정보는 다음 방법으로 언제든 삭제할 수 있습니다(앱 안에는 따로 삭제 버튼이 없습니다).

  • 기기 설정: 앱 정보 → 저장공간 → 데이터 삭제, 또는 앱 제거
  • 백업 파일(photo_crop_backup*.json): 기기의 다운로드 폴더에서 파일 관리 앱으로 삭제(앱을 지워도 이 파일은 남을 수 있습니다)
  • 저장된 결과 사진: 갤러리의 PhotoCrop 앨범에서 삭제
  • 광고 ID: 기기 설정 → Google → 광고 에서 초기화하거나 삭제
