개인정보처리방침 — 데이터 사용량

English

최종 수정일: 2026년 9월 29일

Owlmakers(이하 "개발자")는 데이터 사용량(이하 "본 앱")을 이용하는 사용자의 개인정보를 중요하게 생각하며, 아래와 같이 처리 방침을 안내합니다.

1. 데이터 사용량 기록 — 이 기기를 떠나지 않습니다

본 앱은 WiFi·모바일·테더링 데이터 사용량과 앱별 사용량을 보여주기 위해 안드로이드의 사용 기록 접근(사용량 통계) 권한을 사용합니다. 이 권한은 사용자가 설정 화면에서 직접 켭니다.

  • 읽은 사용량 수치와 앱 목록은 기기 안에서만 계산·표시하며, 개발자의 서버나 제3자에게 전송하지 않습니다.
  • 앱을 통계에서 제외한 목록, 요금제 한도·시작일도 기기 안에만 저장됩니다.

2. 위치 권한 — WiFi 이름을 읽는 데만 씁니다

안드로이드는 연결된 WiFi 이름과 주변 WiFi 목록을 보려면 위치 권한을 요구합니다.

  • 본 앱은 위치 권한을 WiFi 이름·주변 네트워크를 표시하는 데만 사용합니다.
  • 위치 좌표를 읽거나 저장하거나 전송하지 않습니다.
  • 위치 권한을 허용하지 않아도 앱은 동작하며, WiFi 이름과 주변 네트워크만 보이지 않습니다.

3. 기기에 저장되는 정보

다음 정보는 사용자 기기 내부에만 저장되며 외부로 전송되지 않습니다.

항목 내용
요금제 설정 월 데이터 한도, 테더링 한도, 요금제 시작일, 경고 비율
속도 측정 기록 다운로드·업로드 속도, 지연, 측정에 쓴 데이터량, 측정한 WiFi 이름
앱 설정 테마, 언어, 알림 설정, 통계에서 제외한 앱

앱을 삭제하면 위 정보도 함께 삭제됩니다.

4. 인터넷 속도 측정 — M-Lab

속도 측정은 사용자가 [측정 시작]을 누를 때만 M-Lab(Measurement Lab, 비영리 인터넷 측정 연구)의 공개 서버와 통신합니다.

  • 측정 과정에서 M-Lab 서버는 사용자의 IP 주소와 측정값(속도·지연 등)을 받으며, 이는 M-Lab 의 정책에 따라 공개 연구 데이터로 남습니다. 측정 화면에서도 이를 안내합니다.
  • M-Lab 개인정보 정책: https://www.measurementlab.net/privacy/
  • 측정을 하지 않으면 M-Lab 과 통신하지 않습니다.

5. 광고 — Google AdMob

본 앱은 무료 이용을 위해 화면 위쪽에 Google AdMob 배너 광고를 표시합니다.

  • AdMob 은 광고 제공을 위해 광고 ID(AAID) 및 기기 정보를 수집할 수 있습니다.
  • 이는 Google 의 처리 방침에 따르며, 개발자는 해당 정보를 별도로 수집·보관하지 않습니다.
  • Google 의 광고 데이터 처리: https://policies.google.com/technologies/ads
  • 광고 개인화 설정: 기기 설정 → Google → 광고 에서 변경할 수 있습니다.
  • 유럽 경제 지역(EEA)·영국 사용자에게는 첫 실행 시 광고 동의(UMP) 창을 제공합니다.

6. 이용 통계 — 앱 개선용 익명 통계

본 앱은 어떤 기능이 실제로 쓰이는지 파악하기 위해 익명 이용 통계를 수집합니다.

  • Google Analytics for Firebase — 어떤 화면을 열었는지 같은 앱 이용 기록과 설치본마다 무작위로 부여되는 앱 인스턴스 ID. Google 의 처리 방침: https://policies.google.com/privacy
  • 개발자 운영 현황 집계 — 앱 버전, 표시 언어, 실행마다 새로 만드는 무작위 식별자, 화면·기능 사용 이벤트를 개발자 서버(api.owlmakers.com)로 보내 실시간 사용 현황을 집계합니다.
  • 보내지 않는 것 — 데이터 사용량 수치, 앱별 사용량, WiFi 이름, 위치, 이름·이메일·전화번호 등 개인을 식별할 수 있는 정보. 무작위 식별자는 특정 개인과 연결되지 않습니다.

7. 알림

상시 알림(지금 속도·오늘 사용량)과 한도 경고 알림은 기기 안에서 만들어 표시합니다. 알림은 설정에서 끌 수 있습니다.

8. 만 14세 미만 아동

본 앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 고의로 수집하지 않습니다.

9. 사용자 권리

본 앱은 계정·회원가입이 없어 개발자가 보관하는 개인정보가 없습니다. 기기 내 정보는 앱을 제거하여 언제든 지울 수 있습니다.
