개인정보처리방침 — 내 IP 확인 - 공인·내부·IPv6

최종 수정일: 2026년 10월 13일 · English

Owlmakers는 「내 IP 확인 - 공인·내부·IPv6」(My IP Address - Public & Local)의 정보 처리 방법을 안내합니다.

핵심 요약
· 계정·로그인이 없습니다. IP 확인 기능을 위한 개발자 서버나 서버 프록시가 없습니다.
· 공인 IP는 사용자가 조회를 누르고 접속 안내를 확인한 뒤에만 외부 HTTPS 서비스 ipify에 요청합니다. 조회 시 외부 서비스에 IP가 남을 수 있습니다. 무로그·익명 접속을 보장하지 않습니다.
· 로컬 주소·DNS·게이트웨이·SSID·기록·백업 원문을 개발자나 광고·통계 이벤트에 넣지 않습니다. 사용자가 선택 공유하면 고른 정보가 선택한 앱으로 전달됩니다.
· 광고(AdMob), Google Analytics for Firebase, 개발자 공용 이용 통계(Pulse)는 별도의 네트워크 통신을 합니다. 따라서 앱 전체가 오프라인이거나 모든 정보가 기기를 떠나지 않는다고 약속하지 않습니다.

1. 공인 IP 조회 — 외부 서비스

사용자가 조회를 요청하고 안내에 동의하면 IPv4는 https://api.ipify.org, IPv6는 https://api6.ipify.org 로 접속합니다. HTTPS 연결 과정에서 외부 서비스는 연결 IP를 볼 수 있고, 서비스 운영 및 접속 기록에 IP가 남을 수 있습니다. 로컬 주소·DNS·SSID·기록·백업 파일을 요청 본문으로 보내지 않습니다. 개발자가 요청을 중계하거나 조회 IP를 서버에 저장하지 않습니다.

서비스 안내: https://www.ipify.org

서비스의 이용약관·상업 이용 조건과 실제 보존 기간은 확인하지 못했습니다. 광고 앱의 이용 허용 여부는 출시 전에 사람이 확인할 항목입니다. 서비스의 가용성이나 로그 미보관을 개발자가 보장하지 않습니다.

2. 기기 안의 정보와 기록

  • 기기가 제공하는 인터페이스별 주소, 연결 종류, DNS, 게이트웨이를 표시합니다. Android 버전·망에 따라 값이 제공되지 않을 수 있습니다.
  • 현재 Android 구현은 위치 권한을 요청하지 않고 SSID도 읽지 않습니다. 화면은 제공되지 않은 값을 미제공으로 표시합니다.
  • 조회 결과는 사용자가 항목을 선택해 기록에 저장했을 때만 기기에 보관합니다. 기록에는 주소·조회 시각·출처·연결 종류·선택 항목이 들어갈 수 있습니다. 자동 백그라운드 조회·자동 IP 기록은 없습니다.
  • 테마·언어·온보딩 확인 여부 등 설정을 기기에 저장합니다.
  • 저장 기록은 기록 화면에서 선택 또는 전체 삭제할 수 있습니다. 삭제해도 이미 내보낸 백업 파일이나 다른 앱으로 공유한 정보는 삭제되지 않습니다.

3. 복사·공유·백업

복사는 원문을 시스템 클립보드로 전달합니다. 공유는 선택 항목과 전송 전 확인을 거쳐 사용자가 고른 앱으로 전달합니다. 이후 처리에는 해당 앱의 방침이 적용됩니다. SSID 같은 민감 항목은 기본 선택에서 제외합니다.

파일 백업에는 저장 기록과 설정이 들어갑니다. 광고·계측의 기기 전용 키는 제외합니다. 백업 파일에 IP 등 민감 정보가 들어갈 수 있으므로 보관·전달 대상을 주의해서 선택하세요. 파일은 기기의 다운로드 저장소에 저장되며 개발자 서버로 업로드하지 않습니다. 앱 제거 후에도 파일은 남을 수 있고 파일 관리 앱에서 직접 삭제할 수 있습니다. 복원은 파일을 읽어 검증한 뒤 사용자 확인을 거쳐 기기에 병합합니다.

4. 광고 — Google AdMob

앱 화면 상단 배너와 종료 확인 창의 네이티브 광고를 사용합니다. 조회·복사·저장 중 전면 광고를 넣지 않습니다. 광고 SDK는 UMP 동의 절차를 거친 뒤 초기화됩니다. 동의가 필요한 지역에서는 광고 동의 양식이 표시될 수 있고 설정의 광고 개인정보 설정에서 선택을 바꿀 수 있습니다.

AdMob은 광고 제공·분석·사기 방지를 위해 IP 주소(대략적인 위치 추정), 앱 상호작용, 진단 정보, 광고 ID 및 앱 세트 ID 등의 식별자를 수집·공유할 수 있습니다. 앱이 조회한 IP·SSID·공유 원문을 광고 파라미터로 넣지 않습니다. 다만 SDK 자체 네트워크 연결에서 IP가 보이는 것은 별개입니다. 전송은 TLS로 암호화됩니다.

Google 광고 정보: https://policies.google.com/technologies/ads

광고 ID는 Android 설정에서 초기화·삭제할 수 있습니다.

5. 이용 통계 — Firebase와 Pulse

Google Analytics for Firebase는 앱 인스턴스 ID·광고 ID, 세션·화면·기기 및 앱 정보, 마스킹된 IP에서 추정한 대략적인 지역 등을 수집할 수 있습니다. 앱의 추가 이벤트는 조회·취소·복사·공유·저장이라는 동작 이름, 주소 종류 이름, 선택 개수만 담습니다. 주소 값·SSID·인터페이스명·공유 원문·백업 파일을 이벤트에 넣지 않습니다. Google 방침: https://policies.google.com/privacy

개발자 공용 통계 서버 https://api.owlmakers.com/v1/pulse 에 릴리스 앱의 화면·동작 이름·개수·앱 버전·표시 언어·광고 클릭 형식·사용 중 신호를 보냅니다. 실행마다 새로 만드는 세션 난수는 영구 기기 식별자가 아닙니다. 서버는 중계 서비스가 제공한 국가·지역·도시 이름을 사용 통계에 활용하며, Pulse 계약상 원본 IP·좌표는 저장하지 않습니다. 통계 원본 보관 기간은 1년입니다. 앱 계정이나 IP 조회 기록은 이 서버에 보관하지 않습니다. 인터넷 연결 과정에서 서버·중계 사업자는 연결 IP를 볼 수 있습니다.

6. 권한과 서비스

인터넷·네트워크 상태·광고 ID 계열 접근은 조회·광고·통계에 사용합니다. 위치·연락처·카메라·마이크·계정 권한을 요청하지 않습니다. 푸시 알림을 사용하지 않으며 Firebase Messaging을 포함하지 않습니다. 백업 복원에는 사용자가 선택한 파일만 읽습니다. 업데이트 안내는 Google Play 앱 내 업데이트 기능을 사용합니다.

7. 삭제·문의·아동

기기 정보는 Android 앱 정보 → 저장공간 → 데이터 삭제 또는 앱 제거로 삭제할 수 있습니다. 백업 파일은 파일 관리 앱에서 삭제하세요. 광고 ID와 Google 처리 데이터는 Google의 제어 및 정책을 따릅니다. 개발자 통계 관련 문의·삭제 요청은 support@owlmakers.com 으로 보낼 수 있습니다. 개발자는 계정·영구 기기 식별자를 수집하지 않아 개별 기록을 특정하지 못할 수 있습니다.

본 앱은 만 14세 미만 아동을 대상으로 설계되지 않았습니다. 방침이 바뀌면 이 페이지에 변경일과 내용을 게시합니다.
