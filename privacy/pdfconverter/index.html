개인정보처리방침 — PDF 이미지 변환 - 여백 자동 자르기

시행일: 2026년 10월 24일 · English

Owlmakers(이하 "개발자")는 「PDF 이미지 변환 - 여백 자동 자르기」(앱 이름 PDF 변환, 영문 표기 PDF Converter, 이하 "본 앱")를 이용하는 사용자의 개인정보를 중요하게 생각하며, 아래와 같이 처리 방침을 안내합니다.

핵심 요약
· 사용자가 고른 PDF와 사진은 기기 안에서만 처리됩니다. 개발자의 서버나 제3자에게 파일 내용·파일 이름·사진을 보내지 않습니다.
· 본 앱에는 계정·로그인·회원가입이 없습니다.
· 본 앱은 저장소 전체 접근·카메라·위치·마이크·연락처 권한을 요청하지 않습니다. 파일은 시스템 파일 선택 화면과 사진 선택 화면에서 사용자가 직접 고른 것만 읽습니다.
· 광고(Google AdMob), 익명 이용 통계(Google Analytics for Firebase)와 개발자의 익명 사용 현황 집계(Owlmakers 서버)는 사용합니다. 파일 내용·파일 이름·페이지 내용·장수 원값은 여기에 포함되지 않습니다.

1. PDF와 사진 — 이 기기를 떠나지 않습니다

  • 사용자가 시스템 파일 선택 화면에서 고른 PDF, 시스템 사진 선택 화면에서 고른 사진, 또는 다른 앱의 공유·열기로 보낸 파일만 읽습니다. 변환(PDF→이미지, 이미지→PDF)과 여백 자르기는 모두 사용자 기기 안에서 이루어집니다.
  • PDF·사진의 내용, 파일 이름, 파일 주소(URI)를 개발자의 서버나 제3자에게 전송하지 않습니다. 파일을 처리하는 부분에는 네트워크 통신이 없습니다.
  • 원본 파일은 바꾸거나 지우지 않습니다. 변환 결과는 기기의 사진 보관함(Pictures/PDF변환 폴더) 또는 다운로드 폴더, 또는 사용자가 고른 저장 위치에 새 파일로 저장됩니다.
  • 미리보기를 위한 임시 파일은 앱 캐시 폴더에 만들어지고, 다른 앱으로 보내는 압축(ZIP) 공유를 위한 임시 파일도 앱 캐시 폴더에 만들어집니다. 모두 기기 안에만 있습니다.
  • 사진·파일 이름·파일 주소·페이지 내용을 광고 요청, 이용 통계, 사용 현황 집계에 넣지 않습니다.

2. 기기에 저장되는 정보

다음 정보는 사용자 기기 안에만 저장되며 개발자에게 전송되지 않습니다.

항목내용
설정변환 기본값(해상도·저장 형식·자르기 방식 등), 테마, 표시 언어, 첫 안내(온보딩) 확인 여부, 광고 노출 횟수와 마지막 노출 시각(전면 광고 빈도 조절용)
작업 대기열·기록변환 작업의 이름(원본 파일 이름), 원본 파일 주소(URI), 선택한 쪽 번호와 손으로 정한 자르기 영역 좌표, 처리 상태, 결과 파일 위치. 앱이 중단돼도 이어서 할 수 있도록 저장합니다.
사용 현황 보관분아래 4항의 익명 사용 현황을 서버로 보내지 못했을 때 다시 보내기 위해 잠시 기기에 두는 이벤트 코드(최대 7일·500건, 넘치면 오래된 것부터 삭제). 파일 이름·경로는 들어 있지 않습니다.
백업 파일위 설정·작업 기록을 담은 pdfconverter_backup*.json 파일. 정보가 바뀔 때마다 기기의 다운로드 폴더에 저장되고, 설정 화면의 「지금 파일로 백업」을 누르면 날짜가 붙은 사본을 따로 만듭니다. 이 파일에는 원본 파일 이름과 파일 주소가 들어 있을 수 있으나 PDF·사진 자체는 들어 있지 않으며, 기기 안에만 있고 개발자에게 전송되지 않습니다.

3. 광고 — Google AdMob

본 앱은 무료 제공을 위해 Google AdMob 광고를 표시합니다(화면 상단 배너, 앱 종료 확인 창·홈·진행·결과·기록 화면의 네이티브 광고, 변환이 끝난 뒤와 공유 화면에서 돌아온 뒤의 전면 광고). 옵션 조작·자르기 조정·변환 진행 중에는 끼어드는 광고를 띄우지 않습니다.

  • AdMob 은 광고 제공을 위해 광고 ID(AAID), IP 주소, 앱 사용 상호작용, 진단 정보를 수집할 수 있습니다. 이는 Google 의 처리 방침에 따르며, 개발자는 해당 정보를 별도로 수집·보관하지 않습니다. PDF·사진·파일 이름은 광고에 전달되지 않습니다.
  • Google 의 광고 데이터 처리: https://policies.google.com/technologies/ads
  • 광고 개인화 설정: 기기 설정 → Google → 광고 에서 변경하거나 광고 ID 를 초기화·삭제할 수 있습니다.
  • 유럽 경제 지역(EEA)·영국 사용자에게는 첫 실행 시 광고 동의(UMP) 창을 제공하며, 동의 절차가 끝나기 전에는 광고 SDK 를 시작하지 않습니다. 설정 화면의 '광고 개인정보 설정'에서 동의를 다시 바꿀 수 있습니다(해당 지역에서만 표시).

4. 이용 통계와 사용 현황

4-1. Google Analytics for Firebase

서비스 개선과 안정성 확보를 위해 Google Analytics for Firebase 로 익명 이용 통계를 수집합니다.

  • 수집 항목 — 어느 화면(홈·작업·기록·옵션·자르기 조정·진행·결과·설정 등)을 열었는지, 어떤 버튼·스위치를 눌렀는지(항목 이름과 켬/끔, 몇 번째 탭 같은 선택 번호), 변환 작업의 결과(성공·실패·취소와 실패 분류: 손상·암호·메모리 부족·저장 공간·읽기 오류·지원하지 않는 형식 등), 변환 방향(PDF→이미지 또는 이미지→PDF)·장수 구간(1-10, 11-100, 100+)·해상도(150/300/600dpi)·자르기 사용 여부. 그리고 설치본마다 무작위로 부여되는 앱 인스턴스 ID와 Google Analytics 가 자동으로 수집하는 정보(세션, IP 주소로 추정한 대략적인 지역, 기기·앱 버전, 광고 ID 등).
  • 수집하지 않는 것 — PDF·사진, 파일 이름, 경로·파일 주소, 페이지 내용, 장수의 정확한 값, 이름·이메일·전화번호 등 개인 식별 정보.
  • 처리 주체 — 수집·처리는 Google 이 수행하며, 개발자는 개인이 식별되지 않는 집계된 통계만 열람합니다. Google 의 처리 방침: https://policies.google.com/privacy

4-2. Owlmakers 사용 현황 집계

앱이 정상적으로 쓰이고 있는지 확인하기 위해 개발자의 서버로 익명 사용 현황을 전송합니다(api.owlmakers.com, HTTPS). 정식(릴리스) 버전에서만 켜집니다.

  • 전송되는 것: 앱 이름·버전·표시 언어, 위 4-1 항과 같은 종류의 화면 이동·버튼 조작·작업 결과 코드, 앱을 쓰는 중이라는 신호, 그리고 앱을 실행할 때마다 새로 만들어지는 무작위 값(저장하지 않으므로 사용자나 기기를 식별하지 않습니다).
  • 서버는 접속 경로에서 국가·시·도·도시 이름만 기록합니다. IP 주소는 저장하지 않으며, 위치 좌표는 앱이 보내지도 않고 받지도 않습니다.
  • 보관 기간은 1년이며 이후 삭제합니다. 제3자에게 제공하지 않습니다.

5. 푸시 알림 구성요소 (Firebase Cloud Messaging)

본 앱에는 Firebase Cloud Messaging(FCM) 구성요소가 포함되어 있으나, 현재 버전은 사용자에게 푸시 알림을 보내지 않으며 앱이 FCM 등록 토큰을 읽어 개발자에게 보내는 기능도 없습니다. 다만 이 구성요소는 Google 이 설치본을 구분하는 식별자(Firebase 설치 ID·FCM 등록 토큰)를 자동으로 만들 수 있으며, 이는 Google 이 처리합니다. 향후 알림 기능을 추가하면 본 방침을 먼저 고칩니다.

6. 개발자 서버

본 앱은 계정이 없고, PDF·사진·파일 이름을 개발자의 서버에 보내지 않습니다. 개발자 서버로 가는 것은 위 4-2 항의 익명 사용 현황뿐입니다.

7. 앱이 요청하는 권한

본 앱은 저장소 전체 읽기, 사진·동영상 읽기, 카메라, 위치, 마이크, 연락처, 계정 권한을 요청하지 않습니다. PDF 는 시스템 파일 선택 화면에서, 사진은 시스템 사진 선택 화면(Android 13 이상) 또는 파일 선택 화면(Android 12 이하)에서 사용자가 고른 것만 읽습니다. Android 9 이하에서만 사진 앨범에 결과를 쓰기 위해 저장소 쓰기 권한을 사용합니다.

인터넷 연결, 네트워크 상태 확인, 광고 ID 접근, 기기 깨움(WAKE_LOCK), 백그라운드 서비스(FOREGROUND_SERVICE), 알림 표시(POST_NOTIFICATIONS) 등은 광고·Firebase 구성요소가 선언하는 권한입니다. 사용자의 PDF나 사진을 읽는 권한이 아니며, 본 앱은 실행 중에 알림 권한을 요청하지 않고 알림을 보내지도 않습니다.

8. 앱 업데이트

새 버전 안내는 Google Play 의 앱 내 업데이트 기능을 사용합니다. 이 과정에서 개발자가 사용자의 정보를 받지 않습니다.

9. 만 14세 미만 아동

본 앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 고의로 수집하지 않습니다.

10. 사용자 권리와 삭제 방법

개발자가 보관하는 개인 식별 정보가 없습니다(익명 사용 현황은 위 4-2 항). 기기 안의 정보는 다음 방법으로 언제든 삭제할 수 있습니다.

  • 기기 설정: 앱 정보 → 저장공간 → 데이터 삭제, 또는 앱 제거(설정·작업 기록·사용 현황 보관분이 지워집니다)
  • 백업 파일(pdfconverter_backup*.json): 기기의 다운로드 폴더에서 파일 관리 앱으로 삭제(앱을 지워도 이 파일은 남을 수 있습니다)
  • 변환 결과: 갤러리의 PDF변환 앨범, 다운로드 폴더, 또는 사용자가 고른 저장 위치에서 삭제
  • 광고 ID: 기기 설정 → Google → 광고 에서 초기화하거나 삭제
