앱 이름: 서버 상태 확인

「서버 상태 확인」(이하 "앱")은 이용자의 개인정보를 소중히 다루며, 대한민국의 「개인정보 보호법」과 Google Play 정책을 지킵니다. 이 방침은 앱이 어떤 정보를 처리하고 어디로 보내는지 설명합니다.

1. 기본 원칙 (회원가입 없음 · 운영자 서버에 이용자 데이터 저장 없음)

앱에는 회원가입·로그인이 없고, 이용자가 넣은 주소·이름·확인 결과를 받아 저장하는 운영자의 서버나 데이터베이스가 없습니다. 이용자가 저장한 대상(이름·주소·확인 방법)과 확인 기록은 이용자의 기기 안에만 저장됩니다. 앱은 위치 권한을 쓰지 않으며 Wi-Fi 이름·연락처·사진·문자도 읽지 않습니다.

2. 처리하는 정보

가. 이용자가 입력해 기기에 저장되는 정보 (운영자 서버로 전송하지 않음)

  • 확인 대상: 이용자가 직접 입력한 이름과 주소(도메인·IP·웹 주소), 앱이 고른 확인 방법(핑·포트·웹·이름 풀이), «멈추면 알려주기» 켬/끔, 마지막 확인 상태와 시각
  • 확인 기록: 대상마다 최근 최대 50개 — 확인 시각, 방법, 결과(응답함·시간 초과 등), 걸린 시간, 웹 응답 코드
  • 조회 기록: 저장하기 전에 확인한 주소 최대 30개 — 주소, 확인 결과(정상·일부 응답·응답 없음), 확인 시각, 걸린 시간. 같은 주소는 한 줄로 합쳐집니다.
  • 설정: 자동 점검 간격, 복구 알림 켬/끔, 표시 언어, 화면 테마
  • 저장 위치: 기기 내부 저장소(SharedPreferences). 앱을 삭제하거나 앱 데이터를 지우면 함께 삭제됩니다.
  • 백업 파일: 이용자가 [설정] → [백업]을 직접 실행할 때만 위 정보가 파일로 만들어지며, 자동으로 어디에도 전송되지 않습니다.

나. 이용자가 지정한 주소로 앱이 직접 접속하는 것 (확인 기능)

앱은 이용자가 «확인»을 누르거나 상태판을 새로 고치거나 자동 점검이 돌 때, 이용자가 넣은 주소로 이 기기에서 직접 접속합니다(핑, TCP 포트 연결, 웹(HTTP/HTTPS) 요청, 이름 풀이). 이 접속은 운영자의 서버를 거치지 않습니다. 접속을 받는 쪽(그 주소를 운영하는 사람·회사·네트워크)에는 이 기기가 접속한 사실(기기가 쓰는 공인 IP 주소 포함)이 접속 기록으로 남을 수 있습니다. 남의 서버를 무리하게 반복 확인하지 않도록 주의해 주세요. 인증서 오류는 이용자가 직접 허용한 대상에서만 무시하고 확인합니다.

다. 폰이 인터넷에 닿는지 확인하는 연결

확인 결과가 «대상이 멈췄다» 인지 «내 폰이 오프라인이다» 인지 가리기 위해, 앱은 확인 때마다 Cloudflare(1.1.1.1, 443번 포트)와 Google(8.8.8.8, 53번 포트) 중 한 곳에 연결이 되는지만 시도합니다. 연결을 맺는 것이 전부이며 앱이 보내는 데이터는 없습니다. 상대는 이 기기의 IP 주소를 볼 수 있습니다.

라. 알림과 자동 점검 (이용자가 대상마다 «멈추면 알려주기»를 켠 경우)

  • 앱이 꺼져 있어도 안드로이드가 허용하는 간격(약 15분 이상, 기기가 정함) 으로 알림을 켠 대상만 점검하고, 연속으로 응답이 없을 때 기기에 알림을 띄웁니다. 이 알림은 앱이 기기 안에서 스스로 만든 것이며 서버에서 보내는 푸시 알림이 아닙니다. 운영자는 푸시 서버를 운영하지 않습니다.
  • 알림을 띄우려면 안드로이드 13 이상에서 이용자의 알림 허용이 필요합니다. 허용하지 않아도 확인 기능은 쓸 수 있습니다.
  • 앱은 상시 실행 서비스를 쓰지 않으며 배터리 최적화 제외를 요구하지 않습니다.

마. 서비스 품질 모니터링과 광고를 위해 자동 수집·전송되는 정보

  • 자체 사용 현황 모니터링 (Owl Pulse)
  • 전송 대상: https://api.owlmakers.com/v1/pulse
  • 보내는 항목: 앱 패키지명·버전·표시 언어, 앱을 켤 때마다 만들어지는 임의의 세션 ID, 설치할 때 한 번 만들어 저장하는 무작위 설치 ID(계정·기기 하드웨어 ID가 아니며, 앱을 지우거나 데이터를 지우면 새 값이 됩니다), 화면 전환과 버튼 누름의 코드 형태 ID(예: board.recheck), 작업 결과(성공·실패·취소와 분류 코드), 상태판 행을 열 때의 상태 이름(정상·일부 응답·응답 없음·확인 전), 앱이 켜져 있다는 신호(15초 간격)
  • 보내지 않는 것: 이용자가 입력한 주소·이름, 확인 결과의 내용, 확인 기록은 보내지 않습니다.
  • 대략적인 위치: 서버가 접속 IP에서 국가·시·도·도시 이름만 뽑아 통계에 쓰며, IP 주소 자체와 위경도는 저장하지 않습니다.
  • Google AdMob (광고): 앱 안 광고(상단 배너, 목록 사이·결과 아래·상세·설정의 네이티브, 종료 화면, 일부 화면 전환 때의 전면 광고)를 보여 주기 위해 광고 식별자, IP 주소, 기기 정보, 광고 상호작용 정보가 처리될 수 있습니다. 동의가 필요한 지역(EEA·영국 등)에서는 Google UMP 동의 창이 먼저 뜹니다.
  • Google Analytics for Firebase (GA4): 익명화된 앱 이용 통계(화면 조회, 버튼 누름 코드, 작업 결과)와 기기 모델·OS 버전이 집계됩니다. Firebase SDK는 설치별 임의 식별자(Firebase 설치 ID)를 만들 수 있습니다. 이용자가 입력한 주소·이름은 전송되지 않습니다.

3. 보유 및 이용 기간

  • 기기에 저장된 정보: 앱 삭제 또는 앱 데이터 삭제 시 즉시 파기됩니다.
  • 모니터링·분석·광고 데이터(Pulse / GA4 / AdMob): 각 시스템의 보관 정책에 따라 일정 기간 보관한 뒤 집계된 통계로만 씁니다.

4. 제3자 제공 및 위탁

앱은 이용자가 넣은 주소·이름·확인 결과를 외부에 제공하지 않습니다. 서비스 운영과 광고를 위해 아래 도구를 씁니다.

받는 자목적처리되는 항목
Google LLC (AdMob, Firebase)광고 게재·성과 측정, 이용 통계광고 식별자, 기기 정보, IP 주소, 앱 이용 통계 (Google 개인정보처리방침: https://policies.google.com/privacy)
OwlMakers (자체 Pulse)앱 오류 감지, 화면 이용 빈도 측정임의 세션 ID·설치 ID, 화면·버튼 코드, 작업 결과 분류, 언어
Cloudflare, Inc. · Google LLC (공개 DNS)폰의 인터넷 연결 여부 확인연결 시도(앱이 보내는 데이터 없음), 기기 IP 주소
이용자가 입력한 주소의 운영자이용자가 요청한 상태 확인접속 요청(기기 IP 주소 포함)

5. 이용자의 권리와 행사 방법

  • 저장 정보 삭제: 대상을 삭제하거나(5초 안에는 되돌릴 수 있음), 조회 기록을 앱에서 한 줄씩 또는 «전체 지우기» 로 지우거나(한 줄 삭제는 5초 안에 되돌릴 수 있음), 앱 데이터를 삭제하거나 앱을 지우면 기기의 정보가 삭제됩니다.
  • 알림 끄기: 대상별 «멈추면 알려주기»를 끄거나 기기 [설정] → [앱] → 알림에서 허용을 해제할 수 있습니다.
  • 광고 설정: 동의가 필요한 지역에서는 [설정] → [광고 개인정보 설정]에서 동의를 바꿀 수 있고, 그 밖의 지역에서는 기기의 Google 광고 설정에서 맞춤 광고를 끌 수 있습니다.

6. 어린이

앱은 어린이를 주 대상으로 하지 않으며, AdMob 광고는 어린이 대상이 아닌 것으로 설정돼 있습니다. 만 13세 미만 이용자의 개인정보를 의도적으로 수집하지 않습니다.

7. 방침의 변경

방침이 바뀌면 이 페이지의 시행일자를 고치고, 중요한 변경은 앱 안 공지나 스토어 등재 정보로 알립니다.
