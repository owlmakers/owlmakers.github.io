최종 수정일: 2026-09-10

1. 요약

앱 로테이트는 계정도 로그인도 없습니다. 이 앱은 서버를 운영하지 않으며, 사용자가 앱에서 만든 설정(선택한 앱 목록·순서·전환 간격·자동화 옵션)은 모두 사용자의 기기 안에만 저장됩니다. 개발자는 그 내용을 볼 수 없습니다.

앱이 외부로 보내는 것은 광고와 익명 사용 통계 두 가지뿐이며, 아래에 그대로 적습니다.

2. 기기 안에만 저장되는 것 (외부 전송 없음)

항목왜 저장하나
선택한 앱의 패키지 이름과 순서다음 실행 때 같은 구성으로 이어가기 위해
전환 간격, 자동화 설정(블루투스 기기·화면 꺼짐·개입 리셋)사용자가 정한 동작을 유지하기 위해
테마·언어 선택, 안내를 본 적 있는지화면 표시를 위해

이 값들은 안드로이드의 앱 전용 저장소에 보관되며, 앱을 삭제하면 함께 삭제됩니다. 개발자에게 전송되지 않고, 개발자가 조회할 수단도 없습니다.

3. 설치된 앱 목록

번갈아 띄울 앱을 고를 수 있어야 하므로, 앱은 홈 화면(런처)에 나타나는 앱의 목록을 조회합니다. 이 목록은 화면에 보여주기 위해서만 쓰이며 외부로 전송하지 않습니다. 사용자가 선택한 앱의 패키지 이름은 위 2항처럼 기기 안에만 저장됩니다.

4. 광고 (Google AdMob)

이 앱은 무료이며 Google AdMob 광고를 표시합니다. 광고 제공을 위해 Google 은 광고 ID(기기 식별자)와 대략적인 기기 정보를 수집할 수 있습니다.

  • Google 의 처리 방침: https://policies.google.com/technologies/partner-sites
  • 유럽 경제 지역·영국 사용자에게는 앱 최초 실행 시 동의 요청 화면이 표시되며, 동의 선택은

앱 설정에서 다시 변경할 수 있습니다.

  • 광고 ID 초기화·맞춤 광고 해제는 기기 설정 > Google > 광고 에서 가능합니다.

5. 사용 통계 (Google Analytics for Firebase)

어떤 화면이 쓰이는지, 어떤 설정이 많이 쓰이는지를 익명 집계로 확인하기 위해 Google Analytics for Firebase 를 사용합니다.

  • 보내는 것: 화면 이름, 로테이션 시작/중지 같은 동작의 종류, 전환 간격 값, 선택한 앱의 개수.
  • ⛔ 보내지 않는 것: 선택한 앱의 이름이나 패키지 이름, 기기에 설치된 앱 목록,

연락처·위치·전화번호·이메일 등 개인을 식별할 수 있는 정보.

7. 아동

이 앱은 아동을 대상으로 하지 않으며, 아동으로부터 개인정보를 의도적으로 수집하지 않습니다.

8. 사용자의 선택

  • 앱 삭제 = 기기에 저장된 모든 설정 삭제.
  • 맞춤 광고 해제·광고 ID 초기화 = 기기 설정에서.
  • 선택 권한(사용 정보 접근·블루투스)은 부여하지 않아도 앱의 기본 동작에 지장이 없습니다.
