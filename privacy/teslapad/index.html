개인정보처리방침 — 테슬패드

최종 수정일: 2026년 11월 19일 (앱 버전 1.0.6) · English

Owlmakers는 「테슬패드」(com.owlmakers.teslapad)의 정보 처리 방법을 안내합니다. 이 앱은 Tesla, Inc.와 관련 없는 비공식 서드파티 앱이며, Tesla와 제휴·후원 관계가 없습니다. Tesla 및 관련 명칭은 해당 회사의 상표입니다.

핵심 요약
· 차량과는 블루투스로 직접 통신합니다. 차량 식별번호(VIN)와 차량 인증 키는 폰 안에만 있고 서버로 보내지 않습니다.
· 위치 권한은 블루투스 검색 때문에 받지만, 위치 값(좌표)은 읽어 저장하거나 서버로 보내지 않습니다.
· 계정·로그인이 없습니다.
· 광고(광고 ID 사용), 익명 사용 통계(Google Analytics for Firebase와 자체 사용 현황), 이상 진단 기록, 푸시 알림 구독이 외부와 통신합니다. 아래 3~7항에 그대로 적었습니다.

1. 기기 안에만 저장되는 정보 (개발자 서버로 전송하지 않음)

항목내용
차량 식별번호(VIN)사용자가 입력한 값. 내 차의 블루투스 이름을 계산하고 차와 연결 세션을 맺는 데만 씁니다. 앱 전용 보안 저장소에 암호화해 보관하며, 자동 백업과 백업 파일에는 넣지 않습니다.
차량 인증 키이 폰에서 만든 전용 키. 안드로이드 Keystore가 보호하는 키로 암호화해 앱 전용 저장소에 보관하며, 앱 밖으로 내보내지 않습니다. 백업에 넣지 않습니다.
설정·패널·자동화언어·테마, 패널 버튼 배치, 자동화 규칙, 화면 선택값, 탐색 화면에서 마지막으로 입력한 값, 출력 그래프 기록(주행 거리와 출력 값), 앱 안 「기록」 화면(차에 보낸 버튼과 결과, 최근 200건)
차 블루투스 기기 선택「차 블루투스에 연결되면 앱 열기」를 쓸 때 사용자가 고른 기기의 이름과 블루투스 주소, 최근 연결 기록
진단 파일기어 변화·연결 상태·송풍 연동 판단 같은 동작 기록(숫자와 짧은 코드). 폰의 다운로드 폴더 아래 teslapad 폴더에 실행마다 새 파일로 남습니다. VIN·좌표·이름은 담지 않습니다. 앱을 지워도 남아 있어 파일 관리 앱에서 직접 지워야 합니다.

2. 백업 파일

설정이 바뀔 때마다 앱은 설정 묶음을 기기의 다운로드 폴더 아래 teslapad 폴더에 JSON 파일로 자동 저장하고, 설정 화면의 「지금 파일로 백업」으로 직접 만들 수도 있습니다. 앱을 다시 설치했을 때 「파일에서 복구」로 되돌리기 위한 것입니다.

  • 담기는 것: 위 1항의 설정·패널·자동화·출력 그래프 기록, 차 블루투스 기기의 이름과 주소, 사용 통계용 임의 설치 ID(5항).
  • 담기지 않는 것: VIN, 차량 인증 키.
  • 이 파일은 폰 안에 있을 뿐 개발자 서버로 전송되지 않습니다. 앱을 지워도 남으므로 파일 관리 앱에서 직접 삭제할 수 있습니다. 안드로이드 시스템 자동 백업(allowBackup)은 사용하지 않습니다.

3. 권한

권한용도
근처 기기(블루투스 스캔·연결)내 차를 찾고 연결해 명령을 보내고 상태를 받기 위해 씁니다.
위치(정확한 위치)안드로이드가 블루투스 검색 결과를 보여 주는 조건으로 요구하는 권한입니다. 차 광고 신호가 위치 용도 선언 없이는 걸러져, 이 권한을 받아야 내 차가 검색됩니다. 위치 값(좌표)을 읽어 저장하거나 서버로 보내지 않습니다. 폰 위치 서비스가 켜져 있는지 여부만 기기 안 진단에 씁니다.
알림「차가 근처에 오면 알려 줘요」(기본 꺼짐)와 「차 블루투스에 연결되면 앱 열기」의 알림, 백그라운드 갱신 중 표시하는 「차와 연결 중」 알림을 위해 씁니다.
포그라운드 서비스(연결된 기기)차와 인증 연결된 동안 앱이 뒤로 가도 연결과 상태 갱신을 이어 가기 위해 「차와 연결 중」 알림을 띄웁니다. 설정의 「백그라운드에서도 차 상태 갱신」으로 끌 수 있고, 연결이 끊기면 멈춥니다. 서비스가 직접 데이터를 읽거나 보내지는 않습니다.
부팅 완료 수신폰을 다시 켠 뒤 「차가 근처에 오면 알려 줘요」의 블루투스 검색을 다시 걸기 위해 씁니다.
다른 앱 위에 표시(선택)사용자가 설정에서 허용한 경우에만, 고른 차 블루투스가 연결될 때 앱을 바로 앞으로 띄웁니다. 허용하지 않으면 알림으로 대신합니다. 다른 앱 위에 광고나 화면을 그리지 않습니다.
인터넷·네트워크 상태, 광고 ID, 푸시 수신, 절전 해제 유지 등광고·Google Firebase 등 앱에 포함된 SDK가 사용하는 권한입니다.

이 앱은 카메라·마이크·연락처·사진·전화·문자·계정·저장소 전체 접근 권한을 요청하지 않습니다. 백업은 기기의 공용 다운로드 폴더에 저장하며 별도 저장소 권한이 필요 없습니다. 복구할 파일은 사용자가 시스템 파일 선택 창에서 직접 고른 것만 읽습니다. 홈링크 실행 같은 기능에서 사용자가 직접 입력한 숫자(좌표 포함)는 블루투스로 차에만 보내며 서버로 보내지 않습니다. 이 값은 폰의 위치가 아닙니다.

4. 광고

이 앱은 무료이며 광고를 표시합니다.

  • 광고는 Unity LevelPlay 광고 중개를 통해 불러옵니다. 앱에는 LevelPlay에 연결되는 광고 네트워크의 연결 부품(Unity Ads, Meta Audience Network, Pangle, Mintegral, Liftoff Monetize, InMobi, DT Exchange)과 Google 광고 SDK가 포함돼 있습니다. 실제로 어떤 네트워크가 광고를 보내는지는 LevelPlay 설정에 따라 달라집니다.
  • 광고를 제공하기 위해 광고 SDK와 광고 네트워크는 광고 ID(기기 식별자), IP 주소와 그에서 추정한 대략적인 지역, 기기·앱 정보, 광고 노출과 상호작용, 광고 로딩 진단 정보를 수집하거나 공유할 수 있습니다. VIN·차량 정보·위치 값은 광고에 전달하지 않습니다.
  • 화면 위쪽 배너와 여러 화면 사이에 광고가 나오고, 전체 화면 광고는 차가 정차 중이거나 연결되지 않았을 때만 나옵니다.
  • 유럽 경제 지역·영국 등 동의가 필요한 지역에서는 Google 사용자 메시징 플랫폼(UMP)으로 동의를 먼저 받은 뒤 광고를 불러옵니다. 동의 선택은 이 지역에서 설정 화면의 「광고 개인정보 설정」으로 바꿀 수 있습니다.
  • 광고 ID는 기기 설정의 Google → 광고(또는 개인정보 보호 → 광고)에서 삭제·재설정하거나 맞춤 광고를 끌 수 있습니다.
  • Google 광고 데이터 처리: https://policies.google.com/technologies/ads

5. 사용 통계

5-1. Google Analytics for Firebase

화면 전환과 기능 사용(버튼·동작의 식별 코드, 성공·실패 결과 코드)을 통계로 수집합니다. VIN·차량 인증 키·위치·차량 상태 값은 이벤트에 넣지 않습니다. Google은 앱 인스턴스 ID, 기기·앱 정보, IP 기반의 대략적인 지역 같은 SDK 자동 수집 정보를 처리할 수 있으며, 완전히 익명이라고 보장하지는 않습니다. Google 처리 방침: https://policies.google.com/privacy

5-2. 자체 사용 현황 (Owlmakers)

앱이 정상적으로 쓰이는지 확인하려고 자체 서버(https://api.owlmakers.com/v1/pulse, HTTPS)로 익명 사용 통계를 보냅니다.

  • 보내는 것: 앱 이름·버전·표시 언어, 화면 이동과 버튼 식별 코드, 앱을 쓰는 중이라는 신호, 광고 로딩 시간과 결과 코드, 앱을 실행할 때마다 새로 만드는 임의의 세션 값, 그리고 설치할 때 한 번 만들어 폰에 저장하는 임의의 설치 ID(같은 설치를 여러 날에 걸쳐 이어서 세는 데만 씀. 이름·계정·기기 고유 번호와 연결되지 않으며 앱 데이터를 지우거나 앱을 지우면 새 값이 만들어짐. 백업 파일을 복구하면 같은 값이 돌아올 수 있음).
  • 서버는 접속 경로에서 국가·시·도·도시 이름만 기록합니다. IP 주소와 위도·경도는 저장하지 않습니다.
  • VIN·차량 키·차량 상태 값·이름·연락처는 보내지 않습니다.
  • 보관 기간은 1년이며 지나면 서버가 자동으로 지웁니다. 제3자에게 제공하지 않습니다.

6. 이상 진단 기록

차와의 통신에서 문제가 생겼을 때(통신 멈춤·시간 초과·예기치 않은 응답·내부 오류)에 한해 그 상황을 설명하는 짧은 진단 줄(오류 종류, 숫자 코드, 내부 오류 위치)을 5-2의 서버로 보냅니다. 정상 동작 기록은 보내지 않으며 보내는 양도 실행 한 번에 30줄, 1분에 6줄로 제한합니다. VIN·차량 이름·키·좌표가 들어 있는 줄은 보내지 않습니다. 이 기록의 보관은 5-2와 같습니다.

7. 푸시 알림 수신 (Firebase Cloud Messaging)

개발자가 보내는 공지·안내 알림을 받으려고 Google Firebase Cloud Messaging을 사용합니다. 앱을 열면 Google이 이 설치본에 알림 등록 토큰을 부여하고, 앱은 앱 이름과 표시 언어에 해당하는 알림 구독 주제 두 가지에 가입합니다. 이 토큰을 개발자 서버로 보내거나 저장하지 않습니다. 알림은 같은 앱·같은 언어의 모든 사용자에게 같은 내용으로 가며 개인 정보를 담지 않습니다. 안드로이드 13 이상의 알림 권한은 앱 안 안내 줄이나 설정의 알림 행을 눌렀을 때, 또는 「차가 근처에 오면 알려 줘요」를 켤 때에만 요청하고, 허용하지 않아도 알림 외의 기능은 모두 쓸 수 있습니다.

8. 앱 업데이트 확인

앱은 Google Play의 앱 내 업데이트 기능으로 새 버전이 있는지 확인합니다. 이 확인은 Google Play가 처리합니다.

9. 삭제와 보관

  • 기기 안의 설정·차량 정보·인증 키: 앱 정보 → 저장공간 → 데이터 삭제, 또는 앱 제거로 지울 수 있습니다. 차에 등록된 키는 차량 화면에서 따로 삭제합니다.
  • 백업 파일과 진단 파일: 앱을 지워도 남으므로 파일 관리 앱에서 직접 삭제합니다.
  • 계정이 없고 개발자가 사용자를 식별할 수 없어, 특정 사용자의 정보를 찾아 지우는 별도 절차는 제공하지 않습니다. 서버의 사용 통계는 1년 뒤 자동 삭제됩니다. Google SDK가 처리한 정보는 Google 정책과 광고·통계 설정을 따릅니다.

10. 아동

이 앱은 18세 미만을 대상으로 하지 않으며, 아동의 정보를 의도적으로 수집하지 않습니다.
