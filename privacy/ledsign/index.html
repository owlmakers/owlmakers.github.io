LED 전광판 개인정보처리방침

시행일: 2026년 10월 12일 · 게시자: Owlmakers · English

Owlmakers(이하 "개발자")는 LED 전광판(LED Board)(이하 "본 앱")을 운영합니다. 본 앱은 입력한 문구를 화면 가득 LED 전광판처럼 보여 주는 앱으로, 계정·로그인이 없고 문구와 설정을 기기 안에만 저장합니다.

핵심 요약
· 사용자가 입력한 전광판 문구와 저장한 설정은 기기 안에만 저장되며, 개발자의 서버나 제3자에게 전송하지 않습니다.
· 계정·로그인·회원가입이 없고, 위치·카메라·마이크·연락처 권한을 요청하지 않습니다.
· 광고(Google AdMob)와 익명 이용 통계(Google Analytics for Firebase, 개발자 자체 서버)는 사용합니다. 전광판 문구는 여기에 포함되지 않습니다.
· 전체화면 송출 화면에는 광고를 표시하지 않습니다.

1. 전광판 문구와 설정 — 이 기기를 떠나지 않습니다

  • 사용자가 입력한 문구, 글자색·배경색·속도·효과 같은 표시 설정, 저장한 프리셋과 즐겨찾기는 개발자의 서버나 제3자에게 전송하지 않습니다.
  • 전광판 표시와 편집, 프리셋 저장은 모두 사용자 기기 안에서만 이루어집니다.
  • 전체화면 송출 중의 화면 켜짐 유지와 최대 밝기는 화면 설정을 바꾸는 기능일 뿐 별도의 정보를 수집하지 않습니다.

2. 기기에 저장되는 정보

다음 정보는 사용자 기기 안에만 저장되며 개발자에게 전송되지 않습니다.

항목내용
현재 전광판 설정문구, 표시 스타일, 글자색·배경색, 크기·속도·방향, 효과 설정
저장한 프리셋사용자가 저장한 문구·설정과 즐겨찾기 표시
송출 옵션·앱 설정송출 시 최대 밝기 사용 여부, 테마(시스템/라이트/다크), 표시 언어, 첫 안내(온보딩) 확인 여부
자동 백업 파일위 정보를 담은 led_board_backup.json 파일. 정보가 바뀔 때마다 기기의 다운로드 폴더에 저장되며, 앱을 다시 설치했을 때 사용자가 설정 화면에서 직접 골라 복구할 수 있습니다. 이 파일은 기기 안에만 있고 개발자에게 전송되지 않으며, 파일 관리 앱에서 사용자가 직접 삭제할 수 있습니다.
공유용 임시 이미지공유할 때 만든 전광판 이미지(led_board_share.png)가 앱의 임시 저장 공간에 만들어집니다.

3. 공유 기능과 클립보드

  • 전광판을 공유하면 전광판 이미지(PNG)와 OWLLED: 설정 코드가 만들어지고, 기기의 공유 창을 통해 사용자가 직접 고른 앱(메신저 등)으로만 전달됩니다. 개발자는 이 내용을 받지 않으며, 공유 서버가 없습니다.
  • 공유할 때 같은 내용이 기기 클립보드에도 복사됩니다.
  • 앱이 화면으로 돌아오거나 사용자가 [불러오기]를 누르면, 앱은 기기 클립보드의 글자에 OWLLED: 코드가 있는지 기기 안에서 확인합니다. 코드가 있을 때만 미리보기를 보여 주며, 클립보드의 다른 내용은 저장하거나 전송하지 않습니다.

4. 광고 — Google AdMob

본 앱은 무료 제공을 위해 Google AdMob 광고를 표시합니다.

  • 광고는 앱의 일반 화면(홈·편집·프리셋·설정 탭) 상단 배너와 앱 종료 확인 창 등에 표시될 수 있으며, 전체화면 송출 화면에는 광고를 표시하지 않습니다.
  • AdMob 은 광고 제공을 위해 광고 ID(AAID), IP 주소, 앱 사용 상호작용, 진단 정보(앱 실행 시간 등)를 수집할 수 있습니다. 이는 Google 의 처리 방침에 따르며, 개발자는 해당 정보를 별도로 수집·보관하지 않습니다.
  • 개발자가 전광판 문구나 저장한 설정을 광고 목적으로 제공하는 일은 없습니다.
  • Google 의 광고 데이터 처리: https://policies.google.com/technologies/ads
  • 광고 개인화 설정: 기기 설정 → Google → 광고 에서 변경할 수 있습니다.
  • 앱 설정 화면의 '광고 개인정보 설정'에서 광고 동의를 다시 바꿀 수 있습니다(해당 지역에서만 표시).
  • 유럽 경제 지역(EEA)·영국 사용자에게는 첫 실행 시 광고 동의(UMP) 창을 제공하며, 동의 절차가 끝나기 전에는 광고 SDK 를 시작하지 않습니다.

5. 이용 통계 (Google Analytics for Firebase)

본 앱은 서비스 개선과 안정성 확보를 위해 Google Analytics for Firebase 를 사용해 익명 이용 통계를 수집합니다.

  • 수집 항목 — 어떤 화면(홈·편집·프리셋·설정 탭, 전체화면 송출 화면)을 열었는지 같은 앱 이용 기록, 설치본마다 무작위로 부여되는 앱 인스턴스 ID, 그리고 Google Analytics 가 자동으로 수집하는 정보(앱 안의 화면 조회·세션, IP 주소로 추정한 대략적인 지역, 광고 ID 등).
  • 수집하지 않는 것 — 이름·이메일·전화번호 등 개인 식별 정보, 그리고 사용자가 입력한 전광판 문구는 수집하거나 전송하지 않습니다.
  • 처리 주체 — 수집·처리는 Google 이 수행하며, 개발자는 개인이 식별되지 않는 집계된 통계만 열람합니다. Google 의 처리 방침: https://policies.google.com/privacy

6. 자체 사용 통계 (Owlmakers)

개발자는 앱이 정상적으로 쓰이고 있는지 확인하기 위해 자체 서버로 익명 사용 통계(국가·지역 포함)를 전송합니다(api.owlmakers.com, HTTPS). 정식 출시 빌드에서만 전송됩니다.

  • 전송되는 것: 앱 이름·버전·표시 언어, 화면 이동 종류(탭 이름, 전체화면 송출 화면 열람 등), 앱을 쓰는 중이라는 신호, 광고를 눌렀다는 사실(광고 종류), 그리고 앱을 실행할 때마다 새로 만들어지는 무작위 값(저장하지 않으므로 사용자나 기기를 식별하지 않습니다).
  • 전송되지 않는 것: 전광판 문구, 프리셋, 설정값, 클립보드 내용, 이름·이메일·전화번호.
  • 서버는 접속 경로에서 국가·시·도·도시 이름만 기록합니다. IP 주소는 저장하지 않으며, GPS 좌표 등 정밀 위치는 받지 않습니다(본 앱은 위치 권한이 없습니다).
  • 보관 기간은 1년이며, 제3자에게 제공하지 않습니다.

7. 앱이 요청하는 권한

본 앱은 위치·카메라·마이크·연락처·사진/파일 읽기 및 쓰기·계정 권한을 요청하지 않습니다. 인터넷 연결(광고·통계), 네트워크 상태 확인, 광고 ID 접근, 화면 켜짐 유지는 앱과 포함된 SDK 의 동작에 필요한 권한이며, 사용자 정보를 읽는 권한이 아닙니다.

8. 앱 업데이트

앱 안에서 새 버전 안내를 받을 때는 Google Play 의 업데이트 기능을 사용합니다. 이 과정에서 개발자가 사용자의 정보를 받지 않습니다.

9. 만 14세 미만 아동

본 앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 고의로 수집하지 않습니다.

10. 사용자 권리

본 앱은 계정·회원가입이 없어 개발자가 보관하는 개인 식별 정보가 없습니다. 기기 안의 정보는 다음 방법으로 언제든 삭제할 수 있습니다.

  • 앱 안: 프리셋 화면의 '내 저장 문구 전체 삭제' 또는 프리셋별 삭제
  • 기기 설정: 앱 정보 → 저장공간 → 데이터 삭제, 또는 앱 제거
  • 자동 백업 파일(led_board_backup.json): 기기의 다운로드 폴더에서 파일 관리 앱으로 삭제 (앱을 지워도 이 파일은 남을 수 있습니다)
  • 광고 ID: 기기 설정 → Google → 광고 에서 초기화하거나 삭제할 수 있습니다.
