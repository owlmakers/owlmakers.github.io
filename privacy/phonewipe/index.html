개인정보처리방침 — 중고폰 흔적 지우기 - 빈 공간 덮기

최종 수정일: 2026년 10월 13일 · English

Owlmakers는 「중고폰 흔적 지우기 - 빈 공간 덮기」(Wipe Free Space Before Selling, com.owlmakers.phonewipe)의 정보 처리 방법을 안내합니다.

핵심 요약
· 개인 파일을 읽거나 직접 삭제하지 않고, 기기의 앱 전용 임시 파일을 쓰고 정리합니다.
· 계정·로그인이 없고 자체 서버로 정보를 보내지 않습니다.
· 광고(AdMob)와 이용 통계(Google Analytics for Firebase)는 Google 서버와 통신합니다. 개인 파일 내용·파일 이름·작업 경로는 보내지 않습니다.
· 빈 공간 덮기는 삭제 보장·복구 불가·보안 인증 또는 공장 초기화 대체를 뜻하지 않습니다.

1. 기기에 저장되는 정보

항목내용
설정언어·테마·선택한 쓰기 방식·온보딩 확인 여부
작업 정보앱 소유 임시 파일 식별자와 작업 상태·실제 쓴 양·회차. 중단 뒤 앱 재실행 시 정리하기 위해 저장
요약 기록작업 시각·방식·실제 쓰기량·소요 시간·처리 범위·보호 여유·종료 및 정리 결과
로컬 백업설정과 요약 기록만 포함한 JSON 파일. 진행 세션·작업 경로·임시 파일·기기 전용 측정값은 복원하지 않음

이 정보는 개발자 서버로 전송되지 않습니다. 작업 파일은 앱 내부 전용 폴더에 만들고 작업 종료·중단 또는 재실행 시 정리합니다. 정리 실패 시 새 작업이 차단됩니다. 시스템 자동 백업은 사용하지 않습니다. Android 29 이상에서는 설정과 요약 기록이 바뀌면 다운로드 폴더의 phone_wipe_backup.json 자동 백업을 갱신하며, 수동 백업은 날짜가 붙은 사본을 만듭니다. Android 28 이하는 저장 창을 사용합니다. 백업에는 개인 파일·임시 작업 파일이 들어가지 않으며 암호화되지 않은 JSON에 작업 시각 등이 포함됩니다. 앱을 제거해도 다운로드 폴더의 백업은 남을 수 있고 파일 관리 앱에서 별도로 삭제해야 합니다. 사용자가 백업을 다른 서비스로 이동·공유하면 그 서비스의 정책이 적용됩니다.

2. 측정과 권한

  • 내부 저장소의 사용 가능량·배터리·열 상태를 기기에서 측정해 작업 가능 여부와 진행을 표시합니다. 측정 원문과 상세 기록을 이용 통계에 보내지 않습니다.
  • 포그라운드 서비스와 알림 권한은 사용자에게 진행 중인 작업을 표시하기 위해 사용합니다. 원격 푸시 알림은 사용하지 않습니다.
  • 인터넷·네트워크 상태·광고 ID 관련 권한은 광고와 Google 통계 SDK가 사용합니다.
  • 위치·카메라·마이크·연락처·계정·저장소 전체 접근 권한을 요청하지 않습니다. 복원할 백업은 사용자가 시스템 파일 선택기에서 직접 고릅니다.

3. 광고 — Google AdMob

  • 화면 상단 배너와 종료 확인 화면 네이티브 광고를 사용합니다. 쓰기·정리 중 전면 광고는 사용하지 않습니다.
  • Google SDK는 IP 주소(대략적인 위치 추정 포함), 광고 ID 등 기기 식별자, 광고와 앱 상호작용, 진단 정보를 수집·공유할 수 있습니다. 개인 파일 내용과 이름은 광고에 전달되지 않습니다.
  • 광고 데이터 처리: https://policies.google.com/technologies/ads
  • 지역별로 필요한 광고 동의는 Google UMP를 통해 요청하며, 동의 절차 전에 광고 SDK를 시작하지 않습니다. 해당되는 경우 설정의 광고 개인정보 항목에서 선택을 변경할 수 있습니다.
  • 기기 설정의 Google → 광고에서 광고 ID를 삭제·재설정하거나 개인화 설정을 변경할 수 있습니다.

4. 이용 통계 — Google Analytics for Firebase

  • 화면 전환과 고정된 쓰기 방식 이름·회차 수·시작·종료 결과 이름을 통계로 수집합니다. 개인 파일·파일명·백업 내용·작업 경로·작업 시각·상세 바이트 수는 커스텀 이벤트에 넣지 않습니다.
  • Google은 앱 인스턴스 ID, 기기·앱 정보, 세션·사용 상호작용, 광고 ID와 IP 기반 대략적인 지역 등 SDK 자동 수집 정보를 처리할 수 있습니다. 이를 완전히 익명인 정보라고 보장하지 않습니다.
  • 개발자는 집계 통계를 이용해 이용 흐름과 안정성을 파악합니다. Google 처리 방침: https://policies.google.com/privacy
  • 자체 서버 현황판 전송은 비활성화되어 있습니다.

5. 삭제와 보관

기기 안의 요약 기록은 앱의 기록 삭제 기능으로 지울 수 있습니다. 앱 정보 → 저장공간 → 데이터 삭제 또는 앱 제거로 로컬 설정·기록·임시 파일을 삭제할 수 있습니다. 사용자가 내보낸 백업은 파일 관리 앱 또는 공유한 서비스에서 별도로 삭제해야 합니다. Google SDK가 처리한 정보의 보관·삭제는 Google 정책 및 광고·통계 설정을 따르며 개발자가 개별 사용자를 식별해 임의로 삭제할 수 있다고 약속하지 않습니다.
